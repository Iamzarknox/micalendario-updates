# MiCalendario Updates

Canal **público** de actualizaciones de MiCalendario.

- Solo contiene `latest.json` y los APK publicados en Releases.
- No contiene código fuente.
- El APK se verifica por SHA-256 antes de instalar.
- La app comprueba este archivo al abrirse.

`latest.json`:

```json
{
  "versionCode": 19,
  "versionName": "1.14.1",
  "apkUrl": "https://github.com/Iamzarknox/micalendario-updates/releases/download/v1.14.1/MiCalendario-1.14.1.apk",
  "sha256": "20AE415DB95E80A421083BC371991F53B4F26D1185AD8518C359357DF3380B3E",
  "notes": "Actualizacion de prueba desde 1.14.0."
}
```
