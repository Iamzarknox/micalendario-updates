# MiCalendario Updates

Canal **público** de actualizaciones de MiCalendario.

- Solo contiene `latest.json` y los APK publicados en Releases.
- No contiene código fuente.
- El APK se verifica por SHA-256 antes de instalar.
- La app comprueba este archivo al abrirse.

`latest.json`:

```json
{
  "versionCode": 29,
  "versionName": "1.15.1",
  "apkUrl": "https://github.com/Iamzarknox/micalendario-updates/releases/download/v1.15.1/MiCalendario-1.15.1.apk",
  "sha256": "E35DF3CE0F68C9008A8D23575033F3BB2470023CD42EF4038B207F34A4DBBDFE",
  "notes": "Actualizacion de prueba desde 1.15.0."
}
```
