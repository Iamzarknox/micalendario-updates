# MiCalendario Updates

Canal **público** de actualizaciones de MiCalendario.

- Solo contiene `latest.json` y los APK publicados en Releases.
- No contiene código fuente.
- El APK se verifica por SHA-256 antes de instalar.
- La app comprueba este archivo al abrirse.

`latest.json`:

```json
{
  "versionCode": 27,
  "versionName": "1.14.9",
  "apkUrl": "https://github.com/Iamzarknox/micalendario-updates/releases/download/v1.14.9/MiCalendario-1.14.9.apk",
  "sha256": "3CB170C4AB82ED6B59B04AF728A446F849555DC6816F0F7DE26E44EA256B9219",
  "notes": "Actualizacion de prueba desde 1.14.8."
}
```
