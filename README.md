# MiCalendario Updates

Canal **público** de actualizaciones de MiCalendario.

- Solo contiene `latest.json` y los APK publicados en Releases.
- No contiene código fuente.
- El APK se verifica por SHA-256 antes de instalar.
- La app comprueba este archivo al abrirse.

`latest.json`:

```json
{
  "versionCode": 17,
  "versionName": "1.13.1",
  "apkUrl": "https://github.com/Iamzarknox/micalendario-updates/releases/download/v1.13.1/MiCalendario-1.13.1.apk",
  "sha256": "D92DF5E064448D8A72EF271791A324B831972F0A54B621D141850C45C0086415",
  "notes": "Instalacion con PackageInstaller y confirmacion de Android."
}
```
