# MiCalendario Updates

Canal **público** de actualizaciones de MiCalendario.

- Solo contiene `latest.json` y los APK publicados en Releases.
- No contiene código fuente.
- El APK se verifica por SHA-256 antes de instalar.
- La app comprueba este archivo al abrirse.

`latest.json`:

```json
{
  "versionCode": 16,
  "versionName": "1.13.0",
  "apkUrl": "https://github.com/Iamzarknox/micalendario-updates/releases/download/v1.13.0/MiCalendario-1.13.0.apk",
  "sha256": "3EC021ACF2AD89FD888A9C7A252D57A66C9DD7DE60E624E1CDF86C9BB4D22644",
  "notes": "Aviso de actualizacion en barra superior y catalogo de emojis ampliado."
}
```
