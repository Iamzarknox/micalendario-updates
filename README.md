# MiCalendario Updates

Canal **público** de actualizaciones de MiCalendario.

- Solo contiene `latest.json` y los APK publicados en Releases.
- No contiene código fuente.
- El APK se verifica por SHA-256 antes de instalar.
- La app comprueba este archivo al abrirse.

`latest.json`:

```json
{
  "versionCode": 25,
  "versionName": "1.14.7",
  "apkUrl": "https://github.com/Iamzarknox/micalendario-updates/releases/download/v1.14.7/MiCalendario-1.14.7.apk",
  "sha256": "319343F944E6A621C7D63F76DA52791B1F7E7C78A1E78E4153537B5C53F3904D",
  "notes": "Actualizacion de prueba desde 1.14.6."
}
```
