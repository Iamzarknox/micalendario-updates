# MiCalendario Updates

Canal **público** de actualizaciones de MiCalendario.

- Solo contiene `latest.json` y los APK publicados en Releases.
- No contiene código fuente.
- El APK se verifica por SHA-256 antes de instalar.
- La app comprueba este archivo al abrirse.

`latest.json`:

```json
{
  "versionCode": 30,
  "versionName": "1.15.2",
  "apkUrl": "https://github.com/Iamzarknox/micalendario-updates/releases/download/v1.15.2/MiCalendario-1.15.2.apk",
  "sha256": "AE76BA1B218F2EA5EACCCDB5779255F0164AD34837DBEC9E60FF80AA9F965AAC",
  "notes": "Emojis e imagenes independientes por mitad diagonal."
}
```
