# MiCalendario Updates

Canal **público** de actualizaciones de MiCalendario.

- Solo contiene `latest.json` y los APK publicados en Releases.
- No contiene código fuente.
- El APK se verifica por SHA-256 antes de instalar.
- La app comprueba este archivo al abrirse.

`latest.json`:

```json
{
  "versionCode": 31,
  "versionName": "1.15.3",
  "apkUrl": "https://github.com/Iamzarknox/micalendario-updates/releases/download/v1.15.3/MiCalendario-1.15.3.apk",
  "sha256": "0EA3C5E35DCE17340BA23814339302DC5B6AA5FFD6EE6C155EFE985292413C0C",
  "notes": "Emojis centrados en el incentro de cada triangulo."
}
```
