# MiCalendario Updates

Canal **público** de actualizaciones de MiCalendario.

- Solo contiene `latest.json` y los APK publicados en Releases.
- No contiene código fuente.
- El APK se verifica por SHA-256 antes de instalar.
- La app comprueba este archivo al abrirse.

`latest.json`:

```json
{
  "versionCode": 21,
  "versionName": "1.14.3",
  "apkUrl": "https://github.com/Iamzarknox/micalendario-updates/releases/download/v1.14.3/MiCalendario-1.14.3.apk",
  "sha256": "DE708B46C72BC5269B7010567B10418174A72149A93FC78DD03B3B11DC133644",
  "notes": "Actualizacion de prueba desde 1.14.2."
}
```
