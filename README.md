# MiCalendario Updates

Canal **público** de actualizaciones de MiCalendario.

- Solo contiene `latest.json` y los APK publicados en Releases.
- No contiene código fuente.
- El APK se verifica por SHA-256 antes de instalar.
- La app comprueba este archivo al abrirse.

`latest.json`:

```json
{
  "versionCode": 15,
  "versionName": "1.12.0",
  "apkUrl": "https://github.com/Iamzarknox/micalendario-updates/releases/download/v1.12.0/MiCalendario-1.12.0.apk",
  "sha256": "A0B2CCE1395273F4B1A735DDDD88968ED744E34BE5A53AEF41443598471D752E",
  "notes": "Autoactualizacion y selector de iconos con emojis, emoticonos e imagenes propias."
}
```
