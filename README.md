# MiCalendario Updates

Canal **público** de actualizaciones de MiCalendario.

- Solo contiene `latest.json` y los APK publicados en Releases.
- No contiene código fuente.
- El APK se verifica por SHA-256 antes de instalar.
- La app comprueba este archivo al abrirse.

`latest.json`:

```json
{
  "versionCode": 23,
  "versionName": "1.14.5",
  "apkUrl": "https://github.com/Iamzarknox/micalendario-updates/releases/download/v1.14.5/MiCalendario-1.14.5.apk",
  "sha256": "748A704978D20376A2C774FF9B857630A239FBA4200D1AB3F7517F39AA80D093",
  "notes": "Actualizacion de prueba desde 1.14.4."
}
```
