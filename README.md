# MiCalendario Updates

Canal **público** de actualizaciones de MiCalendario.

- Solo contiene `latest.json` y los APK publicados en Releases.
- No contiene código fuente.
- El APK se verifica por SHA-256 antes de instalar.
- La app comprueba este archivo al abrirse.

`latest.json`:

```json
{
  "versionCode": 14,
  "versionName": "1.11.0",
  "apkUrl": "https://github.com/Iamzarknox/micalendario-updates/releases/download/v1.11.0/MiCalendario-1.11.0.apk",
  "sha256": "658997C0388BE136A6445A618BB9F4FAE45FC38E317E98C8B2C0D74A5904770A",
  "notes": "Emoticonos en las casillas y dos leyendas por dia."
}
```
